# Q-Catalyst Phase 5: Quantum Simulation Layer

## Overview
Phase 5 implements the **Quantum Simulation Layer** of the Q-Catalyst triage pipeline. It takes the reduced active-site electronic structure representation generated by Phase 4, applies an active-space reduction $(4e, 4o)$, maps the fermionic electronic Hamiltonian onto an 8-qubit operator via the Jordan-Wigner transformation, solves for the exact classical ground state via **CASCI** (Complete Active Space Configuration Interaction), and simulates the **Variational Quantum Eigensolver (VQE)** on a local quantum simulator to evaluate quantum convergence and energy accuracy against the exact reference.

---

## Scientific Methodology & Architecture

### 1. Active-Space Definition: $(4e, 4o)$
The primary active space is defined by **4 active electrons distributed across 4 active spatial molecular orbitals** (HOMO-1, HOMO, LUMO, LUMO+1), corresponding to $2 \times 4 = 8$ spin-orbitals / qubits:
$$\text{Active Space: } (4e, 4o) \implies 8 \text{ Qubits}$$

### 2. Second-Quantized Electronic Hamiltonian
The active-space electronic Hamiltonian is constructed from 1-body integrals $h_{pq}$ and 2-body Coulomb/exchange integrals $g_{pqrs}$:
$$H_{\text{fermion}} = E_{\text{core}} + \sum_{p,q, \sigma} h_{pq} a_{p,\sigma}^\dagger a_{q,\sigma} + \frac{1}{2} \sum_{p,q,r,s, \sigma, \tau} g_{pqrs} a_{p,\sigma}^\dagger a_{r,\tau}^\dagger a_{s,\tau} a_{q,\sigma}$$

### 3. Jordan-Wigner Qubit Mapping
Fermionic creation and annihilation operators are mapped to Pauli spin operators:
$$a_j^\dagger = \frac{1}{2}(X_j - iY_j) \bigotimes_{k<j} Z_k, \quad a_j = \frac{1}{2}(X_j + iY_j) \bigotimes_{k<j} Z_k$$
This yields an exact 8-qubit `SparsePauliOp` Hamiltonian with a deterministic SHA-256 hash.

### 4. Exact Reference: CASCI
CASCI performs exact matrix diagonalization of the Hamiltonian within the particle-conserving Fock subspace (Hamming weight $N_e = 4$), providing the exact non-relativistic ground state reference energy $E_{\text{CASCI}}$.

### 5. Variational Quantum Eigensolver (VQE)
- **Initial State**: Hartree-Fock state $|11110000\rangle$.
- **Ansatz**: Parameterized `TwoLocal` circuit ($R_y$ rotation layers + $CZ$ entangling gates) with depth $D$ and parameters $\vec{\theta}$.
- **Expectation Value**: Evaluated via Qiskit statevector simulation:
  $$E(\vec{\theta}) = \langle \psi(\vec{\theta}) | H | \psi(\vec{\theta}) \rangle$$
- **Optimizer**: Classical optimization (`COBYLA`, `SPSA`, `L-BFGS-B`) iteratively minimizing $E(\vec{\theta})$.
- **Error Metric**: Absolute error $\Delta E = |E_{\text{VQE}} - E_{\text{CASCI}}|$.

### 6. Optional Noise Simulation
Using Qiskit Aer, controlled depolarizing and readout noise models can be applied to evaluate noise resilience.

## File Contracts & Outputs

1. **`quantum/quantum_results.parquet`**: Master quantum results table.
2. **`quantum/vqe_history.parquet`**: Full iteration-by-iteration optimization trajectory.
3. **`quantum/quantum_manifest.json`**: Machine-readable manifest of active space, qubit Hamiltonian, CASCI reference, and VQE convergence.
4. **`quantum/active_space_manifest.json`**: Detailed orbital indices and integral properties.
5. **`quantum/hamiltonians/*.json`**: Serialized qubit Hamiltonian Pauli strings and coefficients.

## Execution Guide

### Standard VQE Simulation:
```bash
python -m quantum.evaluate --chem-results chemistry/chem_results.parquet
```

### With Simulated Quantum Noise:
```bash
python -m quantum.evaluate --chem-results chemistry/chem_results.parquet --noise
```

## Scientific Scope & Methodological Disclaimers

> [!IMPORTANT]
> - **Classical Simulation of a Quantum Algorithm**: All quantum calculations are executed on a local classical statevector simulator (Qiskit / Aer). This does NOT represent physical quantum hardware execution.
> - **No Quantum Advantage Claimed**: The $(4e, 4o)$ simulation is an algorithmic validation experiment to demonstrate VQE convergence against the exact CASCI classical reference within the triage pipeline.
> - **Active Space Rationale**: The $(4e, 4o)$ space captures the frontier reaction orbitals but does not replace full correlated multireference electronic structure for complete enzyme dynamics.
